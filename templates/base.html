{% comment %} base.html - The MASTER TEMPLATE that all other templates extend. TEMPLATE INHERITANCE: Django templates use inheritance, just like Python classes: 1. base.html defines the overall page structure (HTML skeleton) 2. Other templates "extend" it and fill in specific sections Think of it like a picture frame -- base.html is the frame, and each page template is the picture that goes inside. HOW IT WORKS: base.html defines "blocks" -- placeholder sections that child templates can override: {%% block title %%}LMS{%% endblock %%} <-- default title is "LMS" {%% block content %%}{%% endblock %%} <-- content area (empty by default) A child template (e.g., dashboard.html) extends this and fills in the blocks: {%% extends "base.html" %%} {%% block title %%}Student Dashboard{%% endblock %%} {%% block content %%}

Welcome, {{ user.first_name }}!

{%% endblock %%} The result: the full HTML page with navbar, footer, etc., but with "Student Dashboard" as the title and the dashboard content in the body.
